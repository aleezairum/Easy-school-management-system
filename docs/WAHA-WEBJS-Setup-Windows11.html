WAHA (WEBJS Engine) Setup on Windows 11 + Docker

WhatsApp HTTP API for the EasySchool Management System  |  Engine: WEBJS   Generated 2026-06-12

Maqsad (Purpose): Yeh guide aapko Windows 11 par Docker ke through WAHA ko WEBJS engine ke sath chalana sikhati hai, phir EasySchool API ko us se connect karna. Aapki app already /api/sendText aur /api/sendFile endpoints, X-Api-Key header, session default aur country code 92 use karti hai — yeh setup usi ke mutabiq hai.

1. WAHA aur WEBJS engine kya hai?

WAHA (WhatsApp HTTP API) ek self-hosted server hai jo WhatsApp ko ek simple REST API mein convert kar deta hai. Aap HTTP request bhej kar messages/files send kar sakte hain — koi official WhatsApp Business API ki zaroorat nahi.

  • WEBJS — WhatsApp Web ko emulate karta hai (whatsapp-web.js library). Free, QR-code login. EasySchool ke liye recommended.
  • NOWEB — halka engine, kam RAM. (Alternative)

4. WAHA container chalayein (WEBJS engine ke sath)

Yeh sabse important command hai. WHATSAPP_DEFAULT_ENGINE=WEBJS se WEBJS engine force hoti hai, aur WAHA_API_KEY aapki app ke X-Api-Key se match hona chahiye.

docker run -d `
  --name waha `
  --restart always `
  -p 3000:3000 `
  -e WHATSAPP_DEFAULT_ENGINE=WEBJS `
  -e WAHA_API_KEY=4c4662668dff4e48997492b11d4e7754 `
  -e WHATSAPP_HOOK_EVENTS=session.status `
  -e WAHA_PRINT_QR=false `
  -v waha_sessions:/app/.sessions `
  devlikeapro/waha
Command samjhein:
  • -d — background mein chalayega
  • --restart always — PC restart hone par container khud start ho jayega
  • -p 3000:3000 — WAHA http://localhost:3000 par milega
  • WHATSAPP_DEFAULT_ENGINE=WEBJS — WEBJS engine
  • WAHA_API_KEY=... — yeh wahi key hai jo aapki appsettings.json mein hai. Iske bina API protected nahi hogi.
  • -v waha_sessions:/app/.sessions — session data save rahega taa-ke har restart par dobara QR scan na karna pade
PowerShell note: Upar backtick ` line continuation ke liye hai. Agar masla ho to poori command ek hi line mein likh dein (har ` hata kar). CMD mein continuation ke liye ^ use hota hai.

Ek line wali (copy-paste safe) version:

docker run -d --name waha --restart always -p 3000:3000 -e WHATSAPP_DEFAULT_ENGINE=WEBJS -e WAHA_API_KEY=4c4662668dff4e48997492b11d4e7754 -v waha_sessions:/app/.sessions devlikeapro/waha

5. (Alternative) docker-compose se chalayein

Agar aap config file mein rakhna chahte hain to ek file docker-compose.yml banayein:

services:
  waha:
    image: devlikeapro/waha
    container_name: waha
    restart: always
    ports:
      - "3000:3000"
    environment:
      - WHATSAPP_DEFAULT_ENGINE=WEBJS
      - WAHA_API_KEY=4c4662668dff4e48997492b11d4e7754
      - WAHA_PRINT_QR=false
    volumes:
      - waha_sessions:/app/.sessions

volumes:
  waha_sessions:

Phir us folder mein:

docker compose up -d

8. "default" session banayein aur QR scan karein

EasySchool session ka naam default use karti hai. Do tareeqe:

Tareeqa A — Dashboard se (aasan)

  1. 1http://localhost:3000/dashboard kholain
  2. 2"Sessions" → session default ko Start karein (agar na ho to naya banayein, naam default)
  3. 3QR code screen par aayega
  4. 4Apne phone par WhatsApp → Settings → Linked Devices → Link a Device → QR scan karein
  5. 5Status WORKING ho jaye to ready hai ✔

Tareeqa B — API se (Swagger / PowerShell)

# 1) Session start karein
curl -X POST http://localhost:3000/api/sessions/default/start `
  -H "X-Api-Key: 4c4662668dff4e48997492b11d4e7754"

# 2) QR code haasil karein (browser mein bhi khol sakte hain)
#    http://localhost:3000/api/default/auth/qr  (X-Api-Key header ke sath)

# 3) Status check karein — "WORKING" aana chahiye
curl http://localhost:3000/api/sessions/default `
  -H "X-Api-Key: 4c4662668dff4e48997492b11d4e7754"
WEBJS pehli dafa: Engine Chromium download/launch karti hai, is liye QR aane mein 20–60 second lag sakte hain. Sabar karein. Agar QR expire ho jaye to refresh karein.

9. EasySchool ko WAHA se connect karein

File: School.API/appsettings.json. Aapki app currently Wasender section parhti hai (historical naam) aur Waha section ko fallback rakhti hai. Local WAHA point karne ke liye BaseUrl ko localhost par set karein:

"Wasender": {
  "BaseUrl": "http://localhost:3000",
  "Session": "default",
  "CountryCode": "92",
  "ApiKey": "4c4662668dff4e48997492b11d4e7754"
}
SettingValueWajah
BaseUrlhttp://localhost:3000Local Docker WAHA
SessiondefaultStep 8 wala session
CountryCode92Pakistan — number ko 92xxxxxxxxxx@c.us banata hai
ApiKey(WAHA_API_KEY jaisa)Header X-Api-Key mein jata hai
Important: appsettings.json ki ApiKey aur container ka WAHA_API_KEY bilkul same hone chahiyein, warna 401 Unauthorized aayega.

10. Test message bhejein

Direct WAHA test (apna number daalein, 92 ke sath, bina 0 ke):

curl -X POST http://localhost:3000/api/sendText `
  -H "X-Api-Key: 4c4662668dff4e48997492b11d4e7754" `
  -H "Content-Type: application/json" `

12. Troubleshooting

MaslaHal
401 UnauthorizedAPI key mismatch — container ka WAHA_API_KEY aur appsettings ki ApiKey same karein. Header X-Api-Key bhejna zaroori.
QR nahi aa rahaWEBJS Chromium load ho rahi hai — 1 min wait, phir docker logs waha dekhein. RAM kam ho to dusri heavy apps band karein.
Session FAILED / STOPPEDSession stop karke dobara start karein. Zaroorat par docker volume rm waha_sessions kar ke fresh QR scan.
Message nahi ja rahaSession status WORKING confirm karein. Number format 92xxxxxxxxxx@c.us ho (leading 0 nahi).
Port 3000 already in useDusra port: -p 3001:3000 aur BaseUrl ko http://localhost:3001 karein.
PC restart ke baad band--restart always diya ho to khud start hoga. Docker Desktop "Start on login" enable rakhein.
Phone disconnect ho jata haiJis phone se QR scan kiya us mein internet on rahe; WhatsApp ko background mein band na karein.
Production tip: Live server par BaseUrl ko https://waha-messaging.dev.crymzee.com (ya aapka domain) rakhein aur localhost sirf development ke liye use karein.
